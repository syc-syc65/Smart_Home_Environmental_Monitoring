# 物联网Web后台管理系统

## 项目简介

这是一个基于Vue3 + Element Plus + ECharts开发的物联网Web后台管理系统，用于管理和监控物联网设备，展示传感器数据，实现设备控制和数据可视化分析。

## 功能特性

### 1. 整体架构
- 左侧固定侧边栏导航（可折叠）
- 顶部导航栏（面包屑、消息通知、个人中心入口）
- 完整的登录/登出功能
- 响应式布局，适配不同屏幕尺寸

### 2. 核心功能模块

#### 数据驾驶舱（首页）
- 实时展示物联网设备采集的传感器数据
- 核心KPI卡片：实时温度、湿度、设备在线率、报警次数
- 多图表可视化：传感器数据趋势、设备状态分布、历史数据统计、报警事件时间线
- 支持时间范围筛选、数据刷新、导出功能

#### 设备管理
- 设备列表页面：展示所有物联网设备的名称、状态、位置、最后在线时间
- 设备详情页面：单设备的实时数据、历史数据曲线、参数配置
- 设备控制功能：远程开关控制、阈值设置、控制指令下发

#### 数据管理
- 历史数据查询：按时间、设备、传感器类型筛选，支持导出Excel
- 数据可视化分析：多维度数据对比、趋势分析
- 报警管理：报警事件列表、报警阈值设置

#### 系统管理
- 用户管理：用户列表、权限分配、角色管理
- 系统日志：操作日志、设备日志、报警日志
- 系统设置：基本设置、数据刷新间隔、数据保留天数

#### 个人中心
- 用户信息修改
- 密码修改
- 系统偏好设置（主题、语言、时区、通知）

## 技术栈

- **前端**：Vue3 + Element Plus + ECharts + Pinia + Vue Router
- **构建工具**：Vite
- **数据可视化**：ECharts
- **UI框架**：Element Plus
- **状态管理**：Pinia
- **路由**：Vue Router

## 开发指南

### 新增设备类型
1. 在 `src/views/Devices.vue` 中添加新的设备类型选项
2. 在 `src/views/DeviceDetail.vue` 中添加对应的传感器数据展示
3. 在 `src/views/Data.vue` 中添加对应的数据分析图表

### 新增传感器类型
1. 在相关组件中添加传感器类型定义
2. 更新数据模型和图表配置
3. 调整阈值设置和报警规则

### 自定义主题
1. 修改 `src/App.vue` 中的全局样式
2. 调整 Element Plus 的主题配置
3. 更新图表颜色方案
